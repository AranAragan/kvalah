# Dynamic expansion

Adding a router row and module leaves existing parameter objects untouched. The reference compares the previous expert weights after adding and training the next expert. Registry clones carry their own identity and retain the parent's CAS bytes. Candidate composition and activated versions store exact checkpoint digests.

The expert gate requires a 1% relative improvement over its pinned Validation control. The model gate allows at most 1% relative deterioration in overall and per-expert Validation NLL. A completed production expert run that passes trusted Validation can queue an expansion of the active composition. Unchanged experts keep their exact checkpoint references. The active version stays in service until an administrator publishes a validated candidate. Rollback selects a previously published ancestor. [Reacceptance](REACCEPTANCE.md)
