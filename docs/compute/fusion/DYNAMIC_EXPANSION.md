# Dynamic expansion

Adding a router row and module leaves existing parameter objects untouched. The reference compares the previous expert weights after adding and training the next expert. Registry clones carry their own identity and retain the parent's CAS bytes. Candidate composition and activated versions store exact checkpoint digests.

The expert gate requires a 1% relative improvement over its pinned Validation control. The model gate allows at most 1% relative deterioration in general and each named expert's Validation NLL. Both gates require administrative evidence. The registry publishes only a validated candidate based on the current active version. Rollback selects a previously published ancestor.
