# Expert aggregation

The reducer receives the expert ID, round ID, exact parent, frozen digest and schema digest, algorithm configuration hash and trusted per-assignment supervised token counts. It verifies declared payload digests, finite values and an L2 limit. Duplicate task IDs and duplicate devices in a round are refused.

Regional accumulators retain unnormalized FP64 numerators and the original token counts. A global step divides by total tokens once. FedAvgM, FedAdam, FedYogi and the DiLoCo-inspired Nesterov outer update apply once to the global pseudo-gradient. FedProx requires a positive local proximal coefficient. The PyTorch helper supports the corresponding local penalty. Training provenance and a worker's faithful execution are distinct from validation of signed claims.

The current aggregator is run through the offline coordinator CLI. The HTTPS reference integration uses one accepted result to commit an isolated expert checkpoint. Autonomous regional coordinators, durable round scheduling and staleness handling for live GPU Fusion workers are open.
