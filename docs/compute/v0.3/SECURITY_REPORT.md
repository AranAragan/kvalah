# Security

Enrollment, pinned TLS, Ed25519 signatures, request nonces, revoke, ownership, task bindings, Research Gate and private local artifact scopes retain their previous enforcement. New chunk routes share those controls, plus active lease, bounded indices and lengths, per-chunk digest and complete payload SHA-256. Complete payloads still undergo exact schema, dtype, finite and token-count checks. The coordinator rejects unreasonable adapter or update L2 norms above 1024. Neither incomplete nor rejected data enters CAS as an accepted update.

Identity authenticates a worker's update, and cannot establish that the requested computation took place. Robust defenses against poisoning and Sybil enrollment, isolation for outside participants, and privacy approval for sending user conversations remain required follow-up. This preview targets enrolled trusted devices. Audit files contain hashes and timings and omit credentials and base model weights.
